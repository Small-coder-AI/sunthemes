# Sunthemes

Автоматическое переключение темы Windows (светлая ↔ тёмная) — по высоте
солнца над горизонтом или по расписанию. Умеет учитывать *реальную*
освещённость по прогнозу облачности: в пасмурный день тёмная тема
включится раньше, а утром светлая — позже.

[English version](README.md)

## Возможности

- **Режим «По солнцу»** — светлая тема, пока солнце выше порога над
  горизонтом (пресет города или свои координаты). Пороги утра и вечера
  настраиваются отдельно; по умолчанию 5° — это примерно 40–60 минут
  после восхода и до заката на широте Москвы, когда в комнате уже (ещё)
  светло. Полярные день и ночь обрабатываются сами собой.
- **Учёт облачности** — почасовой прогноз солнечной радиации с
  [Open-Meteo](https://open-meteo.com/) (без API-ключа): под облаками
  порог поднимается, и тема следует за фактическим светом, а не за
  календарём.
- **Режим «По расписанию»** — два фиксированных времени по часам Windows.
- Окно показывает, во сколько сегодня восход/закат и когда сменится тема.
- Живёт в трее, проверяет раз в минуту, после выхода из сна — сразу.
- Ручные кнопки ☀ / 🌙: выбор держится до следующей автоматической смены
  (вернуть авто раньше — ссылкой в окне или пунктом меню трея).
- Автозапуск с Windows (свёрнутым в трей).
- Ярлык в меню «Пуск» создаётся при первом запуске; ярлык на рабочем
  столе — галочка в настройках.
- Интерфейс на русском или английском (по языку Windows).
- Только один экземпляр; все расчёты с учётом таймзоны.

## Приватность

- Никакой геолокации: используются только координаты, которые ты сам
  выбрал.
- Перед запросом погоды координаты округляются до одного знака
  (~10 км) — точное местоположение не покидает компьютер.
- Ни телеметрии, ни аккаунтов, ни ключей. Единственный сетевой запрос —
  опциональный прогноз Open-Meteo.

## Установка

### Обычный способ (рекомендуется)

1. Открой страницу [релизов](https://github.com/Small-coder-AI/sunthemes/releases)
   и скачай `SunthemesSetup.exe`.
2. Запусти его. При первом запуске Windows SmartScreen может показать
   «Windows защитила ваш компьютер» — нажми **«Подробнее» → «Выполнить в любом
   случае»**. Приложение не подписано платным сертификатом, но исходный код
   открыт.
3. В мастере оставь галки **«Ярлык на рабочем столе»** и **«Запускать при старте
   Windows»** и нажми установить — прав администратора не требуется.

Приложение живёт в трее у часов: кнопки ☀ / 🌙 и настройки.

### Для разработчиков (через uv)

Нужна Windows 10/11. Через [uv](https://docs.astral.sh/uv/)
(Python поставится сам, если его нет):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
uv tool install git+https://github.com/Small-coder-AI/sunthemes
```

Затем в **новом** окне терминала выполни команду `sunthemes` (PATH обновляется
только в новом окне). Консольное окно не откроется — приложение уйдёт в трей и
создаст ярлыки в «Пуске» и на рабочем столе.

Обновление:

```powershell
uv tool upgrade sunthemes
```

## Как это работает

| Что | Где |
|---|---|
| Запись темы | `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize` → `AppsUseLightTheme`, `SystemUsesLightTheme` |
| Уведомление системы | `SendMessageTimeoutW(HWND_BROADCAST, WM_SETTINGCHANGE, …, "ImmersiveColorSet", …)` — флаги пишутся по одному с паузой и повторным broadcast, чтобы реже ловить глюк полуперекрашенной оболочки |
| Высота солнца | [astral](https://github.com/sffjunkie/astral) по координатам; светлая тема — пока солнце выше порога (утром и вечером свой) |
| Реальный свет | почасовая `shortwave_radiation` Open-Meteo — это *среднее за предыдущий час*; из неё считается индекс ясности относительно модели ясного неба (Haurwitz) за тот же час. Под облаками порог поднимается: светлая, пока «ясность × радиация ясного неба» выше радиации ясного неба на пороге. Облака только сокращают светлое окно, не больше чем на `clouds_max_offset_min` (120 мин) с каждой стороны |
| Стабильность | уже случившееся переключение новый прогноз не отменяет — тема не «мигает» туда-обратно |
| Автозагрузка | `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` |

Конфиг и лог: `%USERPROFILE%\.theme_switcher\`
(`config.json`, `theme_switcher.log`). Только в конфиге, без окна:
`clouds_max_offset_min` — на сколько минут облака могут сдвинуть смену.

**Обновление с 1.2.x.** Единый «сдвиг ±N минут» двигал утро и вечер в
одну сторону, поэтому вечер нельзя было сделать раньше, не сделав раньше
и утро. Его заменили порогами высоты солнца — старое значение сдвига
сбрасывается, новые пороги по умолчанию уже сдвигают вечер раньше, а утро
позже.

## Если что-то пошло не так

- Лог: `%USERPROFILE%\.theme_switcher\theme_switcher.log`.
- Сброс настроек: удалить `%USERPROFILE%\.theme_switcher\config.json`.
- Убрать из автозагрузки: снять галку и применить, либо удалить
  значение `ThemeSwitcher` в `HKCU\...\Run`.
